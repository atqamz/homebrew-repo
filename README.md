# atqamz/homebrew-repo

Homebrew tap for [Secondhand's `hand` CLI](https://github.com/atqamz/hand).

## Install

```sh
brew tap atqamz/repo && brew install hand
```

`brew tap atqamz/repo` adds this tap, then `brew install hand` installs the formula it holds.

```sh
brew install atqamz/repo/hand
```

The tap-qualified name makes Homebrew add this tap on demand and install `hand` from it in one step.

Upgrade with:

```sh
brew upgrade hand
```

`Formula/hand.rb` tracks hand's latest stable GitHub release; it is regenerated by
`packaging/homebrew/generate.sh` in the `atqamz/hand` repository.
